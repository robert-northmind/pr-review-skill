How counts work

A PR counts once per day or week, even if you review it again. Weekly totals count distinct PRs, so they can be lower than the sum of the days. Submitted GitHub reviews include comment-only reviews; draft reviews, ordinary comments and AI runs are excluded. Hidden inbox PRs still count here.
